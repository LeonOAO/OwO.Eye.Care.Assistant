# OwO 護眼小助手

OwO 護眼小助手是 Android 全域用眼管控工具，結合使用時間限制、每日解鎖額度，以及遊戲低負載的前鏡頭觀看距離守護。

## 主要功能

### 全域使用時間管控

- 透過 Android 無障礙服務，在其他 App 與遊戲運作時持續計時。
- 螢幕關閉時暫停累計，重新亮屏後繼續。
- 每輪時間用完後顯示全螢幕遮罩。
- 家長 PIN 驗證成功後扣除一次當日解鎖額度，並開始下一輪。

### PIN 與每日解鎖額度

- 家長 PIN 與停止管控 PIN 均至少 4 碼。
- 單次使用時間可設定為 1 至 1440 分鐘。
- 每日可解鎖次數可設定為 0 至 100 次。
- 停止管控 PIN 僅在今日解鎖次數用完後使用。
- 主畫面可手動重置今日已使用的解鎖次數。

### 遊戲低負載距離守護

- 使用 CameraX 前鏡頭與 ML Kit 人臉偵測估算觀看距離。
- 分析解析度固定為 480 × 360。
- 採用 FAST 模式，關閉 Landmark、Contour 與 Classification。
- 每秒最多進行 3 次人臉推論，降低遊戲期間的 CPU、發熱及耗電影響。
- 使用 `STRATEGY_KEEP_ONLY_LATEST`，影格不排隊。
- 距離持續低於 30 公分約 1.2 秒後顯示遮罩。
- 回到 30 公分以上約 0.7 秒後自動解除。
- 距離遮罩優先於時間遮罩。
- 未偵測到人臉時不鎖定。

## 首次設定

1. 安裝並開啟 OwO 護眼小助手。
2. 點選「開啟無障礙服務」，在系統設定中啟用本 App。
3. 設定至少 4 碼的家長 PIN。
4. 視需要設定停止管控 PIN。
5. 輸入每輪使用分鐘數與每日可解鎖次數，點選「儲存使用規則」。
6. 點選「開始管控」。
7. 若要使用距離守護，點選「開啟距離守護」並授予相機權限。
8. 將臉部與手機保持約 30 公分，正對前鏡頭約 2 秒，再點選「進行 30 公分校正」。

## 主畫面控制項

### 系統權限

- **開啟無障礙服務**：前往 Android 無障礙設定。
- **無障礙狀態**：顯示服務是否已啟用。

### 保護設定

- **設定或更新家長 PIN**：保存時間遮罩解鎖密碼。
- **設定或更新停止管控 PIN**：保存額度用完後關閉管控的密碼。

### 時間管控

- **單次使用時間**：設定單輪允許使用的分鐘數。
- **每日可解鎖次數**：設定每天可使用家長 PIN 解鎖的次數。
- **儲存使用規則**：保存時間和額度。
- **開始／停止管控**：切換全域計時管控。
- **重置今日解鎖次數**：將今日已使用次數歸零。

### 守護距離

- **開啟距離守護**：啟動前鏡頭和常駐通知。
- **關閉距離守護**：停止相機分析並清除過近狀態。
- **進行 30 公分校正**：保存目前人臉寬度作為 30 公分參考值。
- **距離狀態**：顯示過近狀態、估算距離、校正狀態與人臉寬度。

## 遮罩操作

### 時間遮罩

1. 輸入家長 PIN。
2. 點選「解鎖並開始下一輪」。
3. 驗證成功後扣除一次額度，遮罩解除並重新計時。
4. 當額度用完後，可輸入停止管控 PIN 並點選「停止管控」。

### 距離遮罩

將手機或臉部拉遠至 30 公分以上並保持約 0.7 秒，遮罩會自動解除。

## 權限與系統要求

- Android 8.0 或更新版本。
- 無障礙服務，用於全域計時和全螢幕遮罩。
- 相機權限，用於前鏡頭距離估算。
- Camera 前台服務通知，用於遊戲或其他 App 前景期間持續守護。

## GitHub Actions 編譯

1. 將專案全部內容上傳至 GitHub Repository 根目錄，包含 `.github`。
2. 前往 **Actions**，選擇 **Build Android APK**。
3. 點選 **Run workflow**。
4. 建置完成後，在 Artifacts 下載 `OwO-EyeCare-Assistant-debug-執行編號`。
5. 解壓縮後取得 `app-debug.apk`。

編譯環境：Ubuntu 24.04、JDK 17、Gradle 8.7，以及 Node.js 24 相容版 GitHub Actions。

## 已知限制

- 距離為人臉框寬度估算值，不是 LiDAR、ToF 或硬體測距結果。
- 光線、鏡頭視角、頭部角度與不同裝置會影響估算，換手機後應重新校正。
- 沒有偵測到人臉時，距離遮罩會解除。
- 當輪使用秒數目前保存在無障礙服務記憶體中，重新啟用服務後會重新計時。
- 手機廠牌的省電與背景限制可能終止距離服務，建議允許 App 在背景執行。
