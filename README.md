# 👁️✨ OwO Eye Care Assistant (OwO 護眼助手)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**OwO Eye Care Assistant** 是一款協助培養良好手機與平板使用習慣的 Android 應用程式。透過距離偵測、定時提醒與 PIN 鎖定，協助您與家人保持適當觀看距離，並記得適時休息。

## 🌟 核心功能說明 (Features)

1. 📏 **智慧距離偵測 (Distance Monitoring)**
   * 完成 30 公分校正後，估算臉部與螢幕的距離。
   * 靠得太近時顯示警示，拉遠後解除；橫向與直向需分別校正。

2. ⏰ **定時休息與提醒模式 (Timer & Reminder Modes)**
   * 設定每次允許使用的時間，點擊 **「提醒模式（點擊切換）」** 選擇提醒方式，選好後會自動保存。
   * **語音**：播放語音提醒。
   * **上橫幅**：在畫面上方顯示文字提醒。
   * **全螢幕 PIN 鎖定**：鎖定畫面，輸入「解除鎖定 PIN」才能繼續使用。
   * **語音及上橫幅**：同時播放語音與顯示文字提醒。

3. 🛑 **全螢幕休息提醒 (App Blocking & Forced Breaks)**
   * 選擇全螢幕 PIN 鎖定模式後，使用時間達到上限時會顯示鎖定遮罩。
   * 輸入解除鎖定 PIN 後解除並重新計時，不會倒數後自動解鎖。

4. 🔐 **安全 PIN 碼保護 (PIN Code Protection)**
   * **解除鎖定 PIN**：解除時間到後的全螢幕鎖定。
   * **停止鎖定 PIN**：停止已啟用的護眼控管或距離偵測。
   * **留空不修改**：修改時間時，PIN 欄位留空即可保留原密碼。

5. 🛡️ **護眼無障礙服務 (Guard Accessibility)**
   * 配合系統無障礙服務，執行時間控管與全螢幕鎖定提醒。
   * 熄屏或系統鎖定時暫停計時與提醒，亮屏並解鎖後依原設定恢復。

6. 📋 **執行紀錄 (Execution Logs)**
   * 在主畫面底部查看服務運作紀錄。遇到問題時，點擊 **「複製紀錄」** 提供內容協助檢查。
   * 點擊 **「清除紀錄」** 可清除紀錄，不影響 PIN、校正或使用時間。

## 🛠️ 安裝說明 (Installation)

### 📥 快速下載安裝 (Download Latest APK)

您可以從本專案的建置紀錄下載 APK，無須自行編譯：

1. 點擊本 GitHub 專案頁面上方的 **Actions** 頁籤。
2. 選擇最近一次成功完成、顯示綠色勾號的建置紀錄。
3. 滑動至頁面下方的 **Artifacts** 區塊。
4. 下載 APK 壓縮檔，解壓縮後取得 `.apk`。
5. 將 APK 傳到 Android 手機或平板，點擊安裝。若系統要求允許此來源安裝，請先確認來源可信。

**安裝後開始使用**：依主畫面開啟必要權限，設定時間與 PIN，再啟動護眼功能；使用距離偵測前，請先完成 30 公分的橫向與直向校正。

### 💻 開發者自行編譯 (Build from Source)

1. **環境準備**：安裝 [Android Studio](https://developer.android.com/studio) 與專案所需的 Android SDK。
2. **取得原始碼**：解壓縮專案，或透過 Git Clone 下載。
3. **開啟專案**：在 Android Studio 選擇 `File > Open`，開啟專案資料夾。
4. **同步與編譯**：完成 Gradle 同步後，連接測試裝置，點擊 `Run` 安裝執行；也可使用本專案的 GitHub Actions 建置流程。

## 🚨 常見安裝與權限問題排解 (Troubleshooting)

### 1. 安裝時遭 Google Play Protect 阻擋

Google Play Protect 可能針對未知或疑似有害的 App 顯示警告、要求掃描或阻擋安裝。警告不一定只是因為 App 沒有上架 Google Play。

* 確認 APK 來自本專案，並依畫面提供的安全檢查流程處理。
* 若顯示有害或封鎖警告，先保存完整警告內容供開發者檢查，不要直接關閉安全防護。
* 若確認為誤判，開發者可依 Google 官方流程提出申訴。

### 2. Android 13 以上「無障礙服務」開關反灰（受限制的設定）

部分裝置會限制自行安裝 App 的敏感設定。請先確認您信任 App 的來源與開發者，再進行以下操作：

1. 開啟系統 **「設定」>「應用程式」**。
2. 找到 **OwO 護眼助手**，進入 App 資訊頁面。
3. 點擊右上角的 **「更多選項」**，查看是否提供 **「允許受限制的設定」** 或 **「解除受限制的設定」**。
4. 依畫面完成驗證，再返回無障礙設定開啟服務。

不同裝置的選單名稱與位置可能不同；若找不到選項，請查看裝置的官方說明。

### 3. 權限已開啟，但服務顯示無效

1. 重新開啟 App，查看底部 **「執行紀錄」**，先複製保存。
2. 到系統無障礙設定，將本 App 的服務關閉後重新開啟。
3. 若持續發生，提供失效的大約時間與紀錄協助檢查。

### 4. 距離偵測沒有讀值

確認相機權限已允許、鏡頭未被遮住，並完成目前使用方向的校正。若相機正被其他 App 使用，請先結束該 App 的相機功能再試。

## ⚠️ 權限使用提示 (Permissions Required)

請了解各項權限的用途，再依需要授權：

* **相機權限 (`CAMERA`)**：用於臉部偵測與估算觀看距離，不用於拍照、錄影或上傳臉部影像。
* **顯示在其他應用程式上層 (`SYSTEM_ALERT_WINDOW`)**：讓距離警示等提醒顯示在其他 App 上方。
* **無障礙服務 (`BIND_ACCESSIBILITY_SERVICE`)**：供時間控管與無障礙鎖定遮罩使用。這是敏感權限，請只授予您信任的 App。
* **前景服務 (`FOREGROUND_SERVICE`)**：讓距離偵測在背景運作時保留服務通知；仍可能受系統資源與背景限制影響，並非保證永不被終止。

執行紀錄保存在裝置本機，不記錄 PIN 或臉部影像。點擊「複製紀錄」後，請自行確認分享對象與內容。
